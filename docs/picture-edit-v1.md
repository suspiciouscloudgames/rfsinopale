# 프로젝션용 2차 편집 — 반복 구간 없음

상·하단 모두 1920×1080, 25fps, 14분 30초. 상단 23개 장면, 바닥 8개 장면. 상영 경로를 유지하기 위해 파일명은 poiesis-upper-v1.mp4, poiesis-floor-v1.mp4를 그대로 사용한다.

같은 촬영 구간을 다시 쓰지 않는다. 긴 원본의 서로 다른 부분만 나눠 사용하며, 위쪽과 바닥 사이에서도 원본을 공유하지 않는다. 편집표 생성 시 심볼릭 링크를 실제 원본 경로로 해석해 구간 겹침과 채널 간 재사용을 검사한다.

선명한 영상을 반복하는 대신 채도가 낮더라도 형태가 남은 작가 클립을 복귀시켰다. 앞부분은 숫자 클립의 기존 순서와 c.mp4, 약 04:41부터 호연의 해변 사람들·밤거리로 이어진다. 상단의 항구 수면은 호연의 IMG_4869.MOV, IMG_4872.MOV 원본이며, IMG_4890.MOV와 IMG_4891.MOV는 밝은 후반부만 사용한다.

초점이 흐리거나 움직임의 번짐이 강한 작가 클립 3.mp4, 4.mp4, 5.mp4, 8.mp4, 13.mp4와 호연 편집본의 235–275초 중첩 구간은 제외했다. 사용자가 삭제한 15.mp4, a.mp4, b.mp4, d.mp4, e.mp4, f.mp4는 복원하지 않았다. 원본은 삭제하지 않는다.

프레임 혼합과 채도 감소·감마 보정을 제거했다. 원본 프레임을 유지하는 25fps 변환, Lanczos 크기 변환, 대비 1.04만 적용한다. 감속으로 인한 프레임 반복은 있을 수 있지만 촬영 구간을 루프하거나 다시 삽입하지 않는다. 기존 원본에 포함된 움직임의 흐림은 남을 수 있다.

상단 전환은 1.2초, 바닥은 2.4초 디졸브다. 바닥 영상은 전용 floor-clips 및 floor.mp4만 사용하며 더 긴 호흡으로 진행한다. 자막별 표시 시간과 문구, Stuck (Final) 음원 루프, 시 엔딩과 시스템 루프는 유지한다. 자막 사이의 쉼만 조정해 90.6초를 줄였으며, 마지막 61.6초와 해파리 연출의 길이는 유지한다.

프로젝터 자막은 터키어 위·영어 아래, 보통 굵기다. 1080p에서 흰색 터키어 약 35px, 하늘색 영어 약 27px. 배경 없이 얇은 윤곽선과 그림자를 사용한다.

## 파일

- 편집표: `content/manifests/picture-edit-v1.json` (version 2)
- 생성: `scripts/build-picture-edit.py`, `scripts/render-picture-edit.py`
- 원본 검토: `output/editing/contact-*.jpg`, `output/editing/sharp-review/`
- 중간 렌더 캐시는 검증 후 삭제하며 필요 시 다시 생성한다.

세로 구름 영상 IMG_4755.mp4는 확대 시 윤곽이 사라져 제외했다.

새 작가 원본 IMG_5611.mov(약 30초)을 상단 11:39.1–12:11.7에 추가했다. 원본 3.0–29.7초를 사용한다. 개를 설명하는 자막과 직접 연결하지 않고, 경계와 머무를 권리를 이야기하는 후반부에 도시의 일상으로 배치했다. 실제 원본은 videos/rf-video/clips/IMG_5611.mov, 통합 편집 폴더에는 youngju__IMG_5611.mov 상대 링크가 있다. 바닥도 같은 14분 30초 길이에 맞추되 원본 순서와 사용 구간을 유지한다.

IMG_5388.MOV의 물고기 양동이 장면은 07:46.2–08:01.8에 약 16초 사용한다. “알아볼 수 있는 형태로 붙잡아두는 일”의 자막 한 문장에 맞췄다. 원본 2.0–18.7초를 사용하고 그만큼 거리 장면을 줄였다. 원본은 videos/rf-video/clips/IMG_5388.MOV, 통합 편집 폴더는 상대 링크다.

재현: scripts/retime-fifteen-minute.py → scripts/build-picture-edit.py → scripts/render-picture-edit.py. 원래 자막 시간표는 content/manifests/subtitle-timing-original.json에 보존한다. 본편 14분 30초 + 해파리 유지 30초 = 한 회차 15분. 완성된 시가 있는 회차는 시 10초와 암전 2초가 추가되어 약 15분 12초다.
