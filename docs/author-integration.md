# 호연 시스템 + 작가 자막·아이패드 통합

기준: `ce39c3a1d2dc160364255f18301bd01f93a5f8f4` (호연, 2026-09-24).
작업 브랜치: `integration/author-tablet-subtitles`.
아이패드 원본: `gamepoem`의 `81c6f34a5dc71a05e1d650d3e25c54fdc3cf89fd`.
원래 작업 폴더와 원격 `gh-pages`는 변경하지 않았다.

## 유지한 구조

호연의 Electron 중앙 제어, 상단 A/바닥 B 출력, 디스플레이 설정, 공통 장면과 해파이 군집, 트리거 영상 및 복구 구조를 유지한다. `shared/show/controller.js`는 변경하지 않는다. 새 상영 프로그램의 실행 시작점은 `desktop/main/main.mjs`이다. 기존 `video/` 브라우저 상영 페이지는 이 통합의 실행 시작점이 아니다.

## 작가 버전으로 반영한 내용

- 수정된 터키어·영어 전문 각 54문장. `assets/video/resonant-field-film/resonant_field_bilingual_timeline.json`의 100개 짝 자막을 사용한다. 터키어 위, 영어 아래. 하단 여백 12%, 기존보다 큰 글자. 해파이 전환 중에도 마지막 자막이 읽힌다.
- 최소 읽기 시간 960.6초(16분 0.6초). A가 더 짧으면 기존 영상의 재생 속도를 낮추어 맞춘다. 더 길면 원래 속도를 유지하고 자막 시간을 비례 확장한다. B는 중앙 시계에 맞춰 원래 속도로 반복한다. 이후 `docs/picture-edit-v1.md`의 새 상·하단 960.6초 편집본을 만들고 기본 상영 파일로 연결했다. 새 편집본은 정상 속도 1배로 재생한다. 상영 전체 길이에는 호연 설정의 해파이 유지 시간과, 완성된 시가 있을 때 10초 표시 및 2초 암전이 추가된다.
- 최신 iPad 가로 UI, 세 언어 전문과 별도의 랜덤 38문장, 사진, 시 조각 편집·정렬·삭제, 책 형태 전체 화면을 `desktop/tablet`에 포함한다. 7개 사진을 사용하는 기존 manifest도 유지한다. 원본에 추가됐지만 아직 등록되지 않은 사진은 임의로 편입하지 않았다.
- 아이패드 문장 완성마다 호연의 `SentenceEvents` 규약으로 전송한다. 언어 변경·정렬·삭제·마무리 버튼은 새 문장 트리거를 만들지 않는다. 세션 ID와 확인 응답으로 재시도 중 중복 집계를 막는다.
- 해파이 유지 뒤 완성된 시가 있으면 상단에 10초 표시 → 두 출력 2초 암전 → 다음 회차 → 해당 시의 아이패드 초기화. 미완성 시는 다음 회차에도 유지한다.
- 작가가 전달한 `Stuck (Final).mp3`를 원래 속도로 반복한다. 다른 파도 소리를 추가하지 않는다.

## 실행과 갱신

Node 22.12 이상에서:

```sh
npm ci
npx install-electron
npm run desktop:preview
```

실전 실행은 `npm run desktop`. 현재 미디어 서버는 **127.0.0.1에만 바인딩**한다. 실제 iPad에서는 통합된 `desktop/tablet`을 배포한 주소를 사용해야 한다. 원래 gamepoem 공개 주소에는 이번 연결 코드가 아직 배포되지 않았다. 공개 배포 및 전시장 iPad/프로젝터 실기 검증은 별도다.

아이패드 원본을 다시 반영할 때:

```sh
npm run tablet:sync -- /absolute/path/to/gamepoem/site
npm test
npm run desktop:verify:author
```

동기화 스크립트는 원본 파일을 복사한 후 설치용 연결 어댑터를 재적용한다. 원본의 UI/언어/사진 파일을 직접 변경하지 않으며, 예상한 연결 코드가 바뀌면 조용히 덮어쓰지 않고 실패한다. `desktop/tablet/snapshot.json`에는 원본 커밋과 입력 파일 해시를 기록한다.

## 검증

- 기존 상영 단위 테스트와 새 아이패드 데이터·네트워크 테스트 39개 통과.
- 수정 자막을 사용자 첨부 전문과 대조하고 54문장/100개 카드 및 최소 읽기 시간을 검사.
- `npm run desktop:verify:author`: 실제 Electron A/B 및 아이패드 창에서 문장 입력, 설치 트리거, 미완성 시 보존, 10초 시 표시, 양쪽 암전, 반복과 초기화 확인. 임시 운영 설정으로 기존 운영자 설정을 보존한다.
- 호연의 A/B 영상 파일은 Git LFS 포인터의 SHA-256과 일치한다. 해당 실제 영상으로 `desktop:verify:author`도 통과했다.

원본 저장소에는 `assets/tiggerVideos/web/IMG_4869.mp4`가 LFS 지정인데 일반 Git blob으로 올라가 있다. 깨끗이 복제해도 수정 표시가 생기며 이번 통합에서는 이 파일을 변경하거나 커밋하지 않는다.
