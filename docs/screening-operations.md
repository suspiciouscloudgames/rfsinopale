# 상영 운영 안내

## 로컬 실행

두 프로젝트를 나란히 둔다: `rfsinopale/`, `gamepoem/`.
`rfsinopale`에서 `python3 scripts/dev-server.py`를 실행한다.

- 상영: http://127.0.0.1:5189/rfsinopale/video/
- 태블릿 조작: http://127.0.0.1:5190/?room=sinopale
- 설정: http://127.0.0.1:5189/rfsinopale/video/settings.html

서버는 로컬 컴퓨터 전용으로 바인딩한다. 다른 물리 태블릿에서 이 127.0.0.1 주소로 연결할 수는 없다. 현장에서는 두 프로젝트를 함께 배포하고 동일한 room 값을 사용한다. 공개 배포 기본 경로는 `/rfsinopale/video/`와 `/gamepoem/`이다. 방당 상영 화면은 하나만 실행한다. 동시 리허설에는 다른 room을 사용한다.

## 기본 동작

시작 버튼 또는 Enter로 시작한다. 브라우저가 허용하면 자동 전체화면에 들어간다. Esc는 전체화면만 해제하고 재생은 계속한다. F는 전체화면, O는 운영 화면 표시/숨김이다. Codex 내장 브라우저는 전체화면 지원이 제한될 수 있다.

종료 60초 전부터 영상·자막·기존 텍스트·트리거영상이 함께 페이드아웃하고 해파이가 등장한다. 영상 종료 후 해파이를 30초 유지한다. 다음 영상의 첫 프레임부터 이전 해파이는 전부 즉시 사라진다. 사운드는 계속 재생한다. 숨겨진 탭은 영상과 대기 카운트가 멈추며 다시 보이면 이어진다.

중앙 문장에 문구를 새로 추가하면 문장트리거 1회다. 제거와 중앙 문장 안 재배치는 집계하지 않는다. 제거 후 다시 추가하면 새로운 1회다. 같은 사건을 통신 경로 두 곳에서 받거나 재전송해도 한 번만 집계한다.

기본 개체 수는 `min(16, max(1, 트리거 횟수))`다. 페이드 중 추가 트리거는 해파이를 추가한다. 대기 중 입력은 다음 회차에 반영한다. 화면 효과는 대기 중 최대 동시 수만큼 합쳐 다음 시작 때 표시하며 횟수 집계는 모두 보존한다. 새로고침은 새 세션으로 시작하며 이전 세션 미확인 이벤트를 버린다. 미전송 큐는 태블릿 메모리 내 보관이며 태블릿 새로고침/종료를 넘어 영구 보존하지 않는다.

트리거영상은 무음으로 8초 이내 1회 재생한다. 화면 가장자리 후보 위치를 번갈아 사용한다. 최대 3개를 동시에 표시하며 입력이 더 오면 가장 오래된 효과를 교체한다. 회차 횟수는 효과 교체와 무관하게 모두 집계한다.

## 설정

설정 화면에서 페이드 시간, 유지 시간, 불투명도, 오버레이 시간/동시 수, 개체 수, 모델/영상 경로를 바꿀 수 있다.

- 시간/해파이 설정은 다음 회차부터 적용된다.
- 트리거영상 설정은 이후 트리거부터 적용된다.
- 기본값은 video/settings.json이며, 브라우저 저장값이 우선한다.
- JSON 내보내기·가져오기로 다른 상영 기기에 설정을 옮긴다.
- 경로는 상영 페이지 기준이다. 같은 사이트의 파일 또는 CORS를 허용한 미디어 URL을 사용한다.
- 모델: animation/jellyfish_slow_swim.glb. 내장 유영 애니메이션을 개체마다 다른 시점으로 재생한다.
- 트리거영상: assets/tiggerVideos의 4개 MOV에서 영상 스트림을 무손실로 옮긴 web/*.mp4. video/trigger-videos.json 목록에서 무작위 선택하며 직전 영상은 제외한다. 원본 MOV는 보존한다. 파일 추가 시 목록도 갱신해야 한다. 화면 전체에서 무작위 지점을 선택한다. 불규칙한 부드러운 경계가 한 점에서 번지며 영상을 드러내고 마지막 구간에서 사라진다. 검은 비네트는 없으며 설정 불투명도는 최대 강도다.
- 매 회차 첫 해파이 1개는 관람자 쪽(카메라 뒤)에서 시작해 카메라를 통과한 뒤 화면 안 우측 상단으로 멀어진다. 카메라 근거리 클리핑을 줄이고 모델 양면을 렌더링해 내부를 스쳐 지나가는 장면을 만든다. 기본 경로에서 카메라 중심 통과는 등장 후 16초, 우측 상단 이동은 23초부터다. 나머지 해파이는 왼쪽 아래에서 오른쪽 위로 서서히 이동한다. 개체마다 크기·깊이를 달리하고 가까운 개체가 더 크게, 빠르게 움직인다. 장시간 표시 시 경계에서 작아졌다가 다시 진입한다. 이전 기본 모델/영상 경로를 저장한 설정은 새 기본값으로 자동 전환하며 시간·불투명도 설정은 유지한다.

O로 연 운영 화면에 회차, 남은 대기 시간, 횟수, 표시 개체 수, FPS, 자산 상태가 나온다. T 키는 운영 화면이 닫혀 있어도 테스트 문장트리거를 1회 발생시킨다. 길게 누를 때의 자동 반복과 Ctrl/Command/Alt 조합, 입력 필드 편집 중에는 발생하지 않는다. 테스트 입력도 실제 집계와 오버레이에 반영되며 대기 중에는 다음 회차에 반영된다. 리허설 도구는 실제 재생 위치/집계를 변경한다. 운영 중 실수로 누르지 않도록 접혀 있다.

## 검증·배포

- `npm test`: 재생/집계/설정/배치/이벤트 큐 테스트. 이벤트 테스트에는 형제 gamepoem 프로젝트가 필요하다.
- `npm run cache`: 정적 JS/CSS/HTML 변경 후 Workbox 캐시 해시 갱신.
- 두 저장소의 변경을 함께 배포해야 중앙 문장 이벤트가 전달된다.
- 업데이트가 실행 중 도착하면 상영을 강제로 재시작하지 않는다. 운영 화면 안내를 확인하고 적절한 시점에 새로고침한다.
- 대용량 기본 영상·오디오·해파이 모델은 사전 캐시하지 않는다. 완전 오프라인 상영은 이번 구현 범위가 아니다.
- Three.js 0.180.0 및 필요한 GLTF 유틸리티를 로컬 vendor에 포함했다. 라이선스는 video/vendor/three/LICENSE에 있다.

- 트리거영상은 기존 대비 가로·세로 2배, 기본 지속시간은 17초다(7초 증가 → 3초 유지 → 7초 감소). 짧은 클립은 원래 속도로 반복하며 번짐 효과는 반복 시 초기화하지 않는다. 기존 브라우저 저장 설정의 지속시간도 17초로 전환하고 이후 저장 시 새 버전을 기록한다. 총 시간을 다시 조정하면 7:3:7 비율로 연출한다. 동시 개수 제한으로 인한 교체와 기본 영상 페이드아웃은 기존대로 적용된다.

- 트리거영상 기본 불투명도는 65%다. 이전 브라우저 저장값도 65%로 전환하며, 이후 운영 설정에서 저장한 값은 유지한다.

- 테스트 E키: 재생 중인 상영 화면에서만 페이드 시작 지점으로 이동한다(기존 리허설 버튼과 동일). 설정 저장·태블릿 이벤트·다른 화면에 영향을 주지 않으며 다음 회차는 정상 재생한다. 키를 누르고 있어도 1회만 처리하고 입력 필드와 조합키에서는 무시한다. 해파이는 기존 페이드/카메라 통과 연출에 따라 등장한다.

- 문장트리거 시 핫핑크(#ff1493), 5px 선 1개를 화면 중앙 높이에서 왼쪽 끝부터 오른쪽 끝까지 7초 동안 수평으로 그린다. 새 트리거는 이전 선을 교체하며 트리거영상의 마지막 7초 동안 선도 사라진다. T키 테스트에도 동일하게 적용된다.
