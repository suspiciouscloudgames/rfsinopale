# 단계별 구현과 점검

2026-09-22. 사용자 지시에 따라 설계에서 구현으로 진행.

기존 설계의 제안값은 조정 가능한 초기값으로 적용한다: 0회도 해파이 1개, 1회당 1개, 최대 16개(실측 후 조정), 대기 중 입력 다음 회차 반영, 사운드 연속 유지, 오버레이 무음. 다음 영상 시작 시 해파이는 즉시 전부 제거한다.

1. 재생 상태/설정 기반: 영상 시간 기반 페이드, 종료 후 대기, 회차 카운터. 순수 로직 테스트로 짧은 영상·0초·회차 경계·10회 반복 확인.
2. 문장트리거: 중앙 문장 신규 추가 이벤트, 고유 ID, 재전송/승인, 상영 iframe 연결. 중복·재연결·재배치 제외 검증.
3. 영상 합성: 가장자리 배치, 부드러운 마스크, 불투명도, 제한된 동시 재생. 배치 범위와 브라우저 재생 검증.
4. 해파이: 제공된 GLB 사전 로드, 깊이 배치, 개체수, 대체 표시, 다음 회차 즉시 제거. 실제 모델 렌더링 및 화면 확인.
5. 운영 설정/통합: 한국어 설정, JSON 가져오기/내보내기, 상태 모니터, 명시적 리허설 기능, 캐시 갱신. 태블릿에서 상영까지 전체 동작 검증.

각 단계는 점검을 통과한 뒤 다음 단계로 진행한다. 결과는 아래에 기록한다.

## 자산
- 해파이: assets/models/haepai/haepai.glb (exports/haepai/haepai-52k-source.glb 원본을 보존하고 런타임 복사본 사용)
- 트리거영상: 임시 assets/hub-background.mp4의 최대 8초, 운영 설정으로 교체
- 최대 16개는 초기 보호값이며 전시장 프로젝터와 기기에서 최종 튜닝 필요

## 점검 결과

1. 완료 — 영상 시간 기반 페이드, 짧은 영상/0초 설정, 마지막 구간 집계, 회차 전환·중복 방지 순수 로직 테스트 통과. 10회 반복은 로직 시뮬레이션으로 검증했다.
2. 완료 — 이벤트 큐/ack/세션 변경 테스트 통과. 실제 태블릿 UI에서 중앙 추가 1회, 제거 시 증가 없음, 재추가 시 2회 확인. 상영 오버레이 발생도 확인했다.
3. 완료 — 가장자리 배치/중앙·자막 회피 테스트 통과. 브라우저에서 연속 입력 18회에 동시 오버레이 3개 상한 확인. 초과 시 오래된 시각 효과만 교체하며 총횟수는 유지한다.
4. 완료 — 실제 GLB 모델 로드, 0회 입력 시 1개, 18회 입력 시 상한 16개 표시 확인. 16개 모두 화면 안에서 크기/깊이를 달리해 표시되는 스크린샷 확인. 현 로컬 내장 브라우저의 짧은 리허설 구간 약 30 FPS; 전시장 성능 보장은 아니다.
5. 완료 — 실제 영상 종료 후 opacity=0, 해파이 유지, 30초 뒤 새 회차 opacity=1·해파이=0 확인. 설정 화면 5초/2초 저장 → 기존 회차 60초/30초 유지·다음 회차 값 변경 확인. 단축 리허설 후 기본값 60초/30초로 복원. 대기 중 이벤트는 다음 회차 pending으로 들어가고 재시작 후 현재 회차 1회로 반영되는 것을 확인. 콘솔 오류 없음.

## 검증 중 수정한 문제

- 단순 Python 정적 서버가 영상 구간 요청을 처리하지 않아 리허설 탐색이 0초로 되돌아갔다. scripts/dev-server.py에 HTTP Range 지원을 넣고 206 / 정확히 1000바이트 응답 및 브라우저 시간 이동을 확인했다.
- 전체화면 요소 밖에 있던 운영 패널을 화면 내부로 이동했다.
- 기존 서비스 워커가 이전 JS를 유지할 수 있었다. 캐시 갱신 스크립트와 상영 페이지의 업데이트 확인을 추가했다. 실행 중 강제 재시작은 하지 않는다.
- 캐시 갱신을 반복 실행해도 메인 앱 캐시 항목을 잃지 않도록 JSON 파싱 및 멱등성을 확인했다.

## 남은 현장 검증

- 다른 물리 기기 사이의 PeerJS/WebRTC 연결과 현장 네트워크 안정성. 이번 브라우저 연동은 같은 컴퓨터에서 확인했다.
- 목표 프로젝터 밝기 및 장시간 실행. Chrome 활성 창에서 F → 전체화면, Esc → 창 모드·재생 유지, F → 재진입은 실제 키 입력으로 확인했다. 자동화의 백그라운드 탭에서는 전체화면 요청이 거절되므로 활성 창에서 확인해야 한다.
- 정식 트리거영상 교체 후 색감/알파/합성 튜닝. 현재는 명시된 임시 영상이다.
- WebGL 컨텍스트 강제 손실 등 장치 장애 시나리오의 현장 확인. 코드에 대체 실루엣 경로가 있다.
