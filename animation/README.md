# 해파리 느린 유영

- 작업 파일: jellyfish_slow_swim.blend
- 원본 백업: jellyfish_original.blend
- 동작 미리보기: jellyfish_swim_preview.mp4 (단색 Workbench, 12 fps)
- 애니메이션: 24 fps, 1–480 프레임, 20초 반복. 481은 루프 연결용 중복 프레임.
- 몸통 수축 주기: 5초. 느린 이동과 기울기는 20초 주기.
- Object Data Properties > Shape Keys에서 몸통, 가장자리, 촉수 변형을 편집할 수 있습니다.
- Graph Editor에서 Soft_Body 및 Drift 액션의 움직임 크기와 속도를 편집할 수 있습니다.
- 원래 메시와 재질을 유지하며 수중 움직임을 제작했습니다. 수중 배경이나 최종 조명 렌더는 포함하지 않습니다.
